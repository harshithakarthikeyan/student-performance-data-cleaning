# Student Performance Data Cleaning & Analysis

## Overview
This project demonstrates data cleaning and basic analysis using Python, Pandas, and NumPy.

## Steps Performed
- Handled missing values
- Converted data types
- Created average marks feature
- Performed correlation analysis
- Identified low-performing students

## Files
- `Students_marksheet_cleaned_code` – Analysis notebook
- `Final_Cleaned_Student_Performance_Dataset` – Cleaned dataset
- `student_performance_dataset` – Original dataset

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
